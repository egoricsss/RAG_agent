# Агент для подготовки к зачёту

Агент на Pydantic AI отвечает на вопросы по курсу «Транслирующие системы»,
используя готовую базу ChromaDB и OpenRouter. При каждом вопросе он сначала
ищет материалы в базе, затем передаёт их модели; при необходимости модель
может выполнить дополнительный поиск. Ответы формируются на русском языке.
В конце каждого ответа приводятся уровень уверенности (высокая, средняя или
низкая) и краткое объяснение на основе найденных материалов. Если материалы не
найдены, уверенность низкая. Это качественная самооценка модели, а не проверенная
вероятность правильности; она может ошибаться и не заменяет проверку источников.
Косинусное сходство при поиске также не является вероятностью правильности ответа.

## Запуск

Требуются Python 3.14, [uv](https://docs.astral.sh/uv/), ключ OpenRouter и
готовая база `chroma_db` с коллекцией `compilers_kb`. Для запросов к OpenRouter
нужны доступ и средства на использование выбранных моделей.

```bash
uv sync
export OPENROUTER_API_KEY="ваш-ключ"
uv run main.py "Что такое транслирующая грамматика?"
```

По умолчанию используются `google/gemini-2.5-flash` для ответов и
`qwen/qwen3-embedding-8b` для поиска. Можно задать переменные окружения:

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `OPENROUTER_API_KEY` | Ключ OpenRouter, обязателен | — |
| `OPENROUTER_CHAT_MODEL` | Модель генерации | `google/gemini-2.5-flash` |
| `OPENROUTER_EMBEDDING_MODEL` | Модель эмбеддингов | `qwen/qwen3-embedding-8b` |
| `CHROMA_DB_PATH` | Путь к базе | `chroma_db` рядом с `agent.py` |
| `CHROMA_COLLECTION` | Имя коллекции | `compilers_kb` |

Модель эмбеддингов должна совпадать с использованной при создании базы,
иначе поиск будет некорректным. Коллекция должна использовать cosine distance.
Агент не создаёт и не пересоздаёт базу или коллекцию.

## Использование из приложения

Интерфейс асинхронный, поэтому его можно будет использовать в обработчике
Telegram-бота. Создавайте экземпляр при запуске приложения и закрывайте при
завершении; каждый вызов `answer` независим, история диалога не сохраняется.

```python
from agent import ExamAgent

async def example():
    async with ExamAgent.from_env() as agent:
        answer = await agent.answer("Что такое синтаксически управляемый перевод?")
        print(answer)
```

## Проверка

```bash
uv run python -m unittest discover -s tests -v
```

Тесты используют локальную временную коллекцию и подставные ответы моделей;
ключ и сетевые запросы для них не требуются. Для реального запуска нужны
OpenRouter и заполненная база. Качество ответа зависит от найденных фрагментов
и модели: проверяйте ответы и указанные источники.
