# Агент для подготовки к зачёту

Агент на Pydantic AI отвечает на вопросы по курсу «Транслирующие системы»,
используя готовую базу ChromaDB и OpenRouter. При каждом вопросе он сначала
ищет материалы в базе, затем передаёт их модели; при необходимости модель
может выполнить дополнительный поиск. Ответы формируются на русском языке.
В конце каждого ответа приводятся уровень уверенности (высокая, средняя или
низкая) и краткое объяснение на основе найденных материалов. Если материалы не
найдены, уверенность низкая. Это качественная самооценка модели, а не проверенная
вероятность правильности; она может ошибаться и не заменяет проверку источников.
Косинусное сходство при поиске также не является вероятностью правильности ответа.

## Запуск

Требуются Python 3.14, [uv](https://docs.astral.sh/uv/), ключ OpenRouter и
готовая база `chroma_db` с коллекцией `compilers_kb`. Для запросов к OpenRouter
нужны доступ и средства на использование выбранных моделей.

```bash
uv sync
export OPENROUTER_API_KEY="ваш-ключ"
uv run main.py "Что такое транслирующая грамматика?"
```

По умолчанию используются `google/gemini-2.5-flash` для ответов и
`qwen/qwen3-embedding-8b` для поиска. Можно задать переменные окружения:

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `OPENROUTER_API_KEY` | Ключ OpenRouter, обязателен | — |
| `OPENROUTER_CHAT_MODEL` | Модель генерации | `google/gemini-2.5-flash` |
| `OPENROUTER_EMBEDDING_MODEL` | Модель эмбеддингов | `qwen/qwen3-embedding-8b` |
| `CHROMA_DB_PATH` | Путь к базе | `chroma_db` рядом с `agent.py` |
| `CHROMA_COLLECTION` | Имя коллекции | `compilers_kb` |

Модель эмбеддингов должна совпадать с использованной при создании базы,
иначе поиск будет некорректным. Коллекция должна использовать cosine distance.
Агент не создаёт и не пересоздаёт базу или коллекцию.

## Закрытый Telegram-бот

Создайте бота через [@BotFather](https://t.me/BotFather) и получите его токен.
Узнайте **числовой ID пользователя** каждого участника (не username и не ID
группы) и укажите их через запятую. Например:

```bash
uv sync
export OPENROUTER_API_KEY="ваш-ключ"
export TELEGRAM_BOT_TOKEN="токен-от-BotFather"
export TELEGRAM_ALLOWED_USER_IDS="123456789,987654321"
# Необязательно: модель должна поддерживать изображения и structured outputs.
export OPENROUTER_VISION_MODEL="google/gemini-2.5-flash"
uv run telegram_bot.py
```

Бот запускается через long polling и работает только пока запущен этот процесс.
Каждый разрешённый пользователь должен открыть личный чат с ботом и отправить
`/start`. Сообщения других пользователей и сообщения из групп игнорируются;
при пустом или некорректном списке ID бот не запустится. Не публикуйте токен
или ключ и не добавляйте их в репозиторий. Изменение списка ID требует перезапуска.

Отправляйте вопросы по одному текстом, отдельной фотографией или альбомом
до 10 фото (не как файлы). Фото одного теста лучше отправлять одним альбомом:
бот ждёт около двух секунд после последнего фото и обрабатывает его целиком.
Подпись к фото передаётся как дополнительный комментарий. Бот показывает
распознанные задания и отвечает на каждое отдельно, используя поиск по базе.
Размер каждого фото ограничен 10 МиБ. Если распознавание ошиблось или фото
нечёткое, отправьте исправленный вопрос текстом. История между запросами
не сохраняется; распознавание и ответы могут ошибаться.

Фото и распознанный текст отправляются в OpenRouter, а сообщения также
проходят через Telegram. Использование моделей может быть платным. При
необходимости выберите другую модель в `OPENROUTER_VISION_MODEL` (по умолчанию
`google/gemini-2.5-flash`); она должна поддерживать входные изображения и
JSON Schema structured outputs через OpenRouter.

## Использование из приложения

Интерфейс асинхронный. Создавайте экземпляр при запуске приложения и закрывайте при
завершении; каждый вызов `answer` независим, история диалога не сохраняется.

```python
from agent import ExamAgent

async def example():
    async with ExamAgent.from_env() as agent:
        answer = await agent.answer("Что такое синтаксически управляемый перевод?")
        print(answer)
```

## Проверка

```bash
uv run python -m unittest discover -s tests -v
```

Тесты используют локальную временную коллекцию и подставные ответы моделей и
Telegram; ключи и сетевые запросы для них не требуются. Для реального запуска нужны
OpenRouter и заполненная база. Качество ответа зависит от найденных фрагментов
и модели: проверяйте ответы и указанные источники.
